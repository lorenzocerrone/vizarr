# jazav sample: `tiff_grid`

A verbatim copy of `samples/tiff_grid` from
[lorenzocerrone/jazav](https://github.com/lorenzocerrone/jazav) at commit
`81e016658e180d535f6a2e7583f7211ada0bf6f7`, written by that project's own
`examples/tiff_grid.py` with zarr-python and the `jazav.reference` codec.

It is here as evidence independent of this repository: `fixtures/local/jazav-v05` is
written by `scripts/make-local-fixtures.mjs` to exercise the parts of the format that
are easy to get wrong, but it is written by us, and a misreading of the spec could land
in both the fixture and the store. This one was written by the reference implementation.

`tiff/virtual.zarr` is a 128x128 uint16 image with three pyramid levels. Level 0 holds no
pixels: one 80-byte reference table under `0/c/0/0/0/0` points at the four uncompressed
64x64 TIFF tiles under `raw/tiff/`, whose pixels start at byte 256 of each file. Levels
1 and 2 are ordinary zstd-compressed arrays, and `tables/` holds two ROI tables.

Not generated by `make-local-fixtures.mjs`; to refresh it, copy the sample again and
update the commit above.
